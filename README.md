# ÉCLAT — אתר איפור אמנותי

אתר תדמית (landing page) לאמנית איפור, בנוי לפי הרפרנס: עיצוב כהה ויוקרתי בגווני רוז-גולד, בעברית עם תמיכה מלאה ב-RTL.

## תכונות
- **Hero** עם כותרת אמנותית, קריאות לפעולה (וואטסאפ + קביעת תור) ותמונת נושא.
- **גלריה** של עבודות איפור.
- **שירותים** — איפור לאירועים, ימי צילום, סדנאות.
- **איך זה עובד** — 4 שלבים (פנייה, אפיון, ביצוע, ליווי).
- **המלצות** בקרוסלה מתחלפת.
- **שאלות נפוצות** באקורדיון.
- **טופס יצירת קשר**.
- **מצב כהה/בהיר** (כפתור בהדר), באנר עוגיות, כפתור וואטסאפ צף.

## הרצה
פתחו את `index.html` בדפדפן — הכל עצמאי (HTML/CSS/JS יחיד), ללא תלות בבנייה.

## התאמה אישית
- מספר הוואטסאפ: החליפו את `972500000000` בקובץ `index.html`.
- תמונות: מוזנות כרגע מ-Unsplash — החליפו בקישורים משלכם.
