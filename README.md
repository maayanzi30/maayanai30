# מעיין זי · אתר-חוויה למאפרת כלות

אתר שבנוי סביב **אובייקט אחד**: פסל תלת־ממדי של ראש כלה עם צעיף וכתר פרחים,
מרונדר בזמן אמת כענן **Gaussian Splats**. הגלילה לא מזיזה את הדף — היא מביימת
את המצלמה. כל פרק הוא שוט: מיקום מצלמה, עומק שדה, גריידינג צבע, ומעבר קולנועי.

```
npm run dev              # שרת סטטי מקומי  → http://localhost:5173
npm run sequence         # מייצר מחדש את רצף התמונות
npm run shots            # מצלם את כל הפרקים בדפדפן אמיתי*
npm run check:fallbacks  # בודק reduced-motion ואת המצב בלי WebGL2*
```

\* שתי הפקודות האחרונות דורשות `npm i -D playwright` ושרת פיתוח שרץ.

אין שלב build ואין תלויות רנטיים. אפשר להעלות את התיקייה כמו שהיא לכל אחסון סטטי
(Netlify / Vercel / Cloudflare Pages / GitHub Pages / S3). דרוש שרת HTTP — לא
לפתוח את `index.html` דרך `file://`, כי ES modules ו‑Web Workers חסומים שם.

## מה יש כאן מבחינה טכנית

### 1. ראסטרייזר Gaussian Splatting אמיתי (WebGL2, ללא ספריות)

`src/splats/` מממש את הצינור המלא:

| שלב | איפה | מה קורה |
|---|---|---|
| קוֹבַרְיאַנְס תלת־ממדי | `shaders.js` | `Σ = R·S·Sᵀ·Rᵀ` מקוואטרניון וסקאלה לכל ספלאט |
| היטל למסך | `shaders.js` | יעקוביאן של ההיטל הפרספקטיבי, `cov2d = J·W·Σ·Wᵀ·Jᵀ` |
| פירוק עצמי | `shaders.js` | ערכים עצמיים של מטריצת 2×2 → צירים ראשי/משני של הבילבורד |
| מיון עומק | `sort.worker.js` | counting sort ב‑16 ביט, מחוץ ל‑main thread |
| שילוב | `renderer.js` | `ONE / ONE_MINUS_SRC_ALPHA` על אינדקסים ממוינים מרחוק לקרוב |

הנתונים יושבים בארבע טקסטורות `RGBA32F` והמיון מעדכן רק buffer של אינדקסים
(attribute עם divisor), כך שאין העתקה של גאומטריה בכל פריים.

**עומק שדה אנליטי:** קונבולוציה של גאוסיאן עם טשטוש איזוטרופי היא בסך הכול
חיבור על האלכסון של הקוֹבַרְיאַנְס. לכן ה‑rack focus כאן הוא מתמטית נכון ולא
פוסט־אפקט — עם תיקון אטימות לפי יחס השטחים כדי לשמר אנרגיה.

### 2. האובייקט

ברירת המחדל היא ענן שנוצר פרוצדורלית (`src/splats/generate.js`) — לא placeholder:
הוא מייצר surfels אמיתיים (דיסקיות שטוחות מיושרות לנורמל של המשטח), בדיוק כמו
סריקה נקייה. ראש עם תבליט מפוסל (רכס גבות, ארובות, עצמות לחיים, אף, שפתיים,
סנטר), קו ריסים וגבות, צוואר וכתפיים, חמש שכבות צעיף, 30 אשכולות פרחים בכתר,
וערפל של חלקיקי זהב.

שני דברים שקובעים אם ענן ספלאטים נראה כמו משטח או כמו רעש:

- **דגימה בפיזור נמוך** — ספירלת פיבונאצ'י על הכדור ורצף R2 על המשטחים
  הפרמטריים, במקום `Math.random()` שיוצר גושים ומרקם מנומר.
- **גודל ספלאט שנגזר מהצפיפות** — המרווח בין דגימות פרופורציוני ל‑1/√N, ולכן
  כל הגדלים מוכפלים ב‑`√(175000/N)`. יחס החפיפה נשאר ~1.25σ בכל רמת איכות.

הצעיף נאלץ תמיד להישאר מחוץ לצללית הגוף (`bodyRadius`) — בלי זה הבד עובר דרך
הגולגולת ונראה כשתי וילונות שטוחים בצדדים.

הספלאטים מתויגים בקבוצות (`GROUP`): עור, צעיף, פרחים, חלקיקים, **שפתיים**,
**עפעפיים**. שתי האחרונות הן מה שהפלטה צובעת.

**להחליף בסריקה אמיתית:** שימי קובץ `.splat` או `.ply` (פורמט INRIA 3DGS)
בתיקייה, ועדכני ב‑`src/scene/chapters.js`:

```js
export const SITE = { splatUrl: 'assets/bride.splat', /* ... */ };
```

זה כל השינוי. `src/splats/loader.js` מפענח את שני הפורמטים, והצינור זהה.

### 3. הבימוי

`src/scene/chapters.js` הוא התסריט — לכל פרק יש מיקום מצלמה, נקודת מבט, FOV,
עומק שדה, אטימות לכל קבוצה, וגריידינג מלא. `src/scene/director.js` מבצע:

- אינטרפולציה **Catmull‑Rom** על מסלול המצלמה (תנועה רציפה, בלי פינות)
- קצב של **החזק → זוז → החזק** בתוך כל מקטע, כדי שאפשר יהיה לקרוא
- **השהיה** מרוככת אחרי הגלילה — הפריים עוקב, לא מרותך
- אפקטי מעבר בשיא התנועה: letterbox, aberration, הבזק לבן קצר, ופיזור ספלאטים
- תנועת מצלמה עדינה ביד חופשית (רעש בתדר נמוך) + פרלקסה מהעכבר
- `camera.shift` — הזזה של המצלמה על צירי המסך, כדי שהאובייקט יישב **מול**
  הטקסט ולא מתחתיו. כל מרחק מצלמה חושב מהמסגור הרצוי:
  `d = (גובה הנושא / אחוז הפריים) / (2·tan(fov/2))`

### 4. Image sequence

`scripts/make-sequence.mjs` מייצר 48 פריימים של משי זורם בלולאה חלקה — מקודד PNG
בעצמו מעל `node:zlib`, בלי תלויות. `src/media/sequence.js` טוען אותם ומשלב אותם
בשיידר הקומפוזיט במצב screen, כשה‑phase נגזר מהגלילה.

**להחליף בחומר אמיתי:** או להחליף את הפריימים ב‑`assets/sequence/` (אותה
שמות־קבצים ו‑`manifest.json`), או להגדיר `SITE.videoUrl` ולקבל וידאו מסונכרן
לגלילה במקום.

### 5. פוסט־פרוססינג

`src/post/` — bright pass, שרשרת bloom בשלוש רמות, aberration כרומטי רדיאלי,
halation, גריין, וינייטה, letterbox, ACES tonemap, ו‑lift/gain לכל שוט.

## ביצועים ונגישות

- שלוש רמות איכות לפי ליבות/זיכרון/סוג מצביע: 320K / 200K / 80K ספלאטים.
  אפשר לכפות רמה עם `?quality=high|balanced|mobile` — שימושי לבדיקת הרנדר
  במכונה שלא מדווחת נכון על החומרה שלה
- רזולוציית רנדר אדפטיבית תוך כדי ריצה לפי זמן הפריים הממוצע
- `prefers-reduced-motion` מבטל את התנועה החופשית ואת אפקטי המעבר
- ללא WebGL2 או ללא JS — הדף הופך למסמך גלילה רגיל עם כל הטקסט
- כל התוכן ב‑HTML סטטי (לא מוזרק מ‑JS), עם `lang="he"` ו‑`dir="rtl"`

## ⚠️ לפני עלייה לאוויר

פרטי הקשר ב‑`index.html` וב‑`src/scene/chapters.js` הם **placeholders**:

```
050-000-0000 · hello@example.com · @example
```

צריך להחליף אותם (גם ב‑`href` של `tel:`, `mailto:`, `wa.me` והאינסטגרם).
