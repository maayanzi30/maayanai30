# ביו-טי — אתר תדמית (איפור לא שגרתי)

אתר תדמית מרובה עמודים בעברית (RTL) עבור **ביו-טי** — איפור לא שגרתי ואמנותי
לאירועים מיוחדים, ימי צילום וסדנאות. נבנה ב-React + Vite + React Router.

## הפעלה מקומית

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לאתר סטטי (תיקיית dist)
npm run preview  # תצוגה מקדימה של הבנייה
```

## מבנה

- **route נפרד לכל עמוד** (`src/pages/`), 8 עמודים:
  בית, תיק עבודות, איפור לאירועים, סדנאות איפור, יצירת קשר,
  הצהרת נגישות, מדיניות פרטיות, תקנון.
- **קומפוננטה נפרדת לכל אזור** (`src/sections/`), 46 אזורים בסך הכול.
- רכיבים משותפים ב-`src/components/` (Header, Footer, טופס נגיש, אקורדיון ועוד).
- מקור אמת אחד לפרטי הקשר והניווט: `src/data/site.js`.

## לפני עלייה לאוויר — לעדכן

1. **מספר וואטסאפ, טלפון ואימייל** ב-`src/data/site.js`.
2. **חיבור הטפסים** לשירות קבלת פניות (כרגע מוצג אישור בצד הלקוח בלבד).
3. **החלפת התמונות** (`ArtImage`) בצילומי איפור אמיתיים, עם שמירה על טקסט חלופי תיאורי.
4. **הצהרת הנגישות** — לוודא שהפרטים והזכאות לפטור מדויקים לעסק.

## נגישות

האתר נבנה לפי עקרונות תקן ישראלי 5568 / WCAG 2.1 AA: HTML סמנטי, ניווט מקלדת,
פוקוס נראה, תוויות טופס מקושרות, הכרזת שגיאות, אקורדיון נגיש וקישור להצהרת
נגישות בפוטר כל עמוד. **זו הנחיית יישום — נדרשת בדיקה ידנית (מקלדת וקורא מסך)
לפני השקה.**
